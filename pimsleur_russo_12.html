Diálogo ​

Sergey telefona para Lena e a convida para jantar.

SergeyЗдра́вствуйте. Скажи́те, Ле́на, не хоте́ли бы вы поу́жинать со мной сего́дня?Olá. Diga, Lena, a senhora não gostaria de jantar comigo hoje?

Conceitos ​

Ao telefone. Алло́ ( - alô). Э́то Серге́й. ( - É o Sergey.)

Quanto eu devo? Ско́лько я до́лжен? ( - Quanto eu devo?) é a pergunta de um homem.

Rublo e números. Рубль ( - rublo) muda com o número: оди́н рубль ( - um rublo), mas пять рубле́й ( - cinco rublos), forma usada de 5 em diante. Do mesmo jeito: во́семь рубле́й ( - oito rublos) e де́сять рубле́й ( - dez rublos).

Números de 11 a 13. Оди́ннадцать ( - onze), двена́дцать ( - doze) e трина́дцать ( - treze). Com rublos: оди́ннадцать рубле́й ( - onze rublos).

Exercícios ​

  1. Atenda o telefone.
  2. Diga ao telefone que é o Sergey.
  3. Convide Lena para jantar com você hoje.
  4. Sugira amanhã à noite.
  5. Pergunte, como homem, quanto você deve.
Respostas
  1. Алло́.
  2. Э́то Серге́й.
  3. Ле́на, не хоте́ли бы вы поу́жинать со мной сего́дня?
  4. Мо́жет быть, за́втра ве́чером?
  5. Ско́лько я до́лжен?

Серёжа ( - Seryozha) é o apelido de Серге́й ( - Sergey). Не могу́ ( - não posso). Лу́чше ( - melhor). У тебя́ ( - na tua casa) é a forma de ты ( - tu) para у вас ( - na sua casa).
