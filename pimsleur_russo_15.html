Pimsleur — Lição 15 ​

Diálogo ​

Lena vai comprar comida, e Sergey quer saber se o dinheiro dela basta.

QuemRussoLatinizadoPortuguês
LenaДо свида́ния, Серге́й.Até logo, Sergey.
SergeyДо свида́ния. Что бы вы хоте́ли де́лать, Ле́на?Até logo. O que a senhora gostaria de fazer, Lena?
LenaЯ собира́юсь купи́ть что́-нибудь пое́сть.Vou comprar alguma coisa para comer.
SergeyУ вас доста́точно де́нег? Ско́лько у вас?A senhora tem dinheiro suficiente? Quanto a senhora tem?
LenaНе о́чень мно́го. У меня́ то́лько не́сколько рубле́й.Não muito. Tenho só alguns rublos.
SergeyСко́лько у вас? Четы́рнадцать и́ли пятна́дцать?Quanto a senhora tem? Catorze ou quinze?
SergeyВот де́сять рубле́й. Сейча́с ско́лько у вас де́нег?Aqui estão dez rublos. E agora, quanto a senhora tem?
LenaНе зна́ю, но сейча́с у меня́ мно́го. Большо́е спаси́бо.Não sei, mas agora tenho bastante. Muito obrigada.

Conceitos ​

Suficiente. Доста́точно ( - suficiente).

Dinheiro. Де́ньги ( - dinheiro) vira де́нег ( - dinheiro) depois de palavras de quantidade: мно́го де́нег ( - muito dinheiro), доста́точно де́нег ( - dinheiro suficiente).

Só. То́лько ( - só, apenas): У меня́ то́лько не́сколько рубле́й. ( - Tenho só alguns rublos.)

Para alguém. Для ( - para) pede o genitivo: для вас ( - para o senhor), для меня́ ( - para mim). Exemplo: Э́то пи́во для вас. ( - Esta cerveja é para o senhor.)

Quanto custa? Сто́ить ( - custar): Ско́лько сто́ит пи́во? ( - Quanto custa a cerveja?) e Пи́во сто́ит оди́н рубль. ( - A cerveja custa um rublo.)

Poder. Мочь ( - poder): Я могу́ ( - eu posso), Я не могу́ ( - eu não posso) e Вы мо́жете? ( - O senhor pode?). Exemplo: Вы мо́жете пообе́дать сейча́с? ( - O senhor pode almoçar agora?)

Exercícios ​

  1. Diga que vai comprar alguma coisa para comer.
  2. Pergunte se a pessoa tem dinheiro suficiente.
  3. Diga que tem só alguns rublos.
  4. Pergunte quanto custa a cerveja.
  5. Diga que hoje não pode.
Respostas
  1. Я собира́юсь купи́ть что́-нибудь пое́сть.
  2. У вас доста́точно де́нег?
  3. У меня́ то́лько не́сколько рубле́й.
  4. Ско́лько сто́ит пи́во?
  5. Сего́дня я не могу́.

Versão informal ​

QuemRussoLatinizadoPortuguês
LenaНу, быва́й, Серёж!Bom, até mais, Serjão!
SergeyДава́й, Лен. А ты куда́ сейча́с, каки́е пла́ны?Até, Lena. E você, vai pra onde agora, quais os planos?
LenaДа вот, хочу́ купи́ть чего́-нибудь перекуси́ть.Ah, quero comprar algo pra beliscar.
SergeyА де́нег-то хва́тит? Ско́лько с собо́й?Mas a grana dá? Quanto você tem aí?
LenaДа не осо́бо, па́ра рубле́й всего́.Quase nada, só uns trocados mesmo.
SergeyСко́лько там, рубле́й четы́рнадцать-пятна́дцать?Quanto tem aí, uns catorze ou quinze rublos?
SergeyНа вот деся́тку. Тепе́рь-то хвата́ет?Toma aí um dezão. Agora dá?
LenaО, тепе́рь с голово́й! Спаси́бочки огро́мное!Opa, agora sobra! Valeuzão mesmo!

Хва́тит ( - vai dar) e хвата́ет ( - dá, basta) falam de ter o suficiente. С собо́й ( - aí com você). Па́ра рубле́й ( - uns trocados). Рубле́й четы́рнадцать ( - uns catorze rublos): a palavra antes do número indica valor aproximado. Деся́тка ( - nota de dez). С голово́й ( - de sobra).
