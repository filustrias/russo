Pimsleur — Lição 25 ​

Diálogo ​

Um motorista pede o caminho para Moscou.

QuemRussoIPAPortuguês
MotoristaИзвини́те.Com licença.
PassanteДа, пожа́луйста.Sim, pois não.
MotoristaВы зна́ете, как лу́чше прое́хать в Москву́ отсю́да?O senhor sabe qual é o melhor caminho daqui para Moscou?
PassanteЕзжа́йте по э́той доро́ге пятьдеся́т киломе́тров.Siga por esta estrada por cinquenta quilômetros.
MotoristaА пото́м?E depois?
PassanteА пото́м езжа́йте по доро́ге нале́во. Москва́ не о́чень далеко́.E depois vá pela estrada à esquerda. Moscou não fica muito longe.

Conceitos ​

Daqui. Отсю́да ( - daqui): Как лу́чше прое́хать в Москву́ отсю́да? ( - Qual o melhor caminho daqui para Moscou?)

Melhor para mim. Com мне ( - para mim) e вам ( - para o senhor), лу́чше ( - melhor) vira um conselho:

  • Мне лу́чше пое́хать напра́во? ( - Seria melhor eu ir para a direita?)
  • Вам лу́чше пое́хать нале́во. ( - É melhor o senhor ir para a esquerda.)

Nada. Ничего́ ( - nada) pede не ( - não) antes do verbo: Вы ничего́ не мо́жете купи́ть. ( - O senhor não pode comprar nada.) O г de ничего́ soa como v.

Por quê. Почему́? ( - Por quê?) e Потому́ что… ( - Porque…).

Lojas e horário. Магази́н ( - loja) e магази́ны ( - lojas). Магази́ны откры́ты. ( - As lojas estão abertas.) Магази́ны закры́ты. ( - As lojas estão fechadas.) Уже́ по́здно. ( - Já é tarde.) Ещё не по́здно. ( - Ainda não é tarde.)

Oitenta. Во́семьдесят ( - oitenta).

Exercícios ​

  1. Pergunte se a pessoa sabe o melhor caminho daqui para Moscou.
  2. Pergunte: Seria melhor eu ir para a direita?
  3. Diga: As lojas estão fechadas.
  4. Diga: Já é tarde.
  5. Pergunte por quê.
Respostas
  1. Вы зна́ете, как лу́чше прое́хать в Москву́ отсю́да?
  2. Мне лу́чше пое́хать напра́во?
  3. Магази́ны закры́ты.
  4. Уже́ по́здно.
  5. Почему́?
